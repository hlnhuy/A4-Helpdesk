# A4 Helpdesk

Hệ thống tiếp nhận và xử lý sự cố mạng (Helpdesk).

## Công nghệ
- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: MySQL

## Cấu trúc
- `frontend/`: giao diện người dùng
- `backend/`: API và nghiệp vụ
- `database/`: SQL tạo bảng và dữ liệu mẫu
- `docs/`: tài liệu dự án
- `storage/`: nơi lưu file tải lên và log (không commit dữ liệu nhạy cảm)

## Trạng thái
Đây là bộ khung thư mục ban đầu. Các file chức năng sẽ được triển khai dần.
